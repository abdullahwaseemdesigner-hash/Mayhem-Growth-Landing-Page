Original web fonts from the Kycron archive supplied by the user:

- Kycron-Regular.woff2: weight 400, section headings and display text.
- Kycron-ExtraLight.woff2: weight 200, cover heading and eyebrow.

Both files are unmodified copies of the archive's WEB/ versions. The CSS in
src/fonts.css registers the two weights, and Vite bundles the files locally.
Inter Regular remains self-hosted through @fontsource/inter for body text.
